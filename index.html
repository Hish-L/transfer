Files over light

Move a file between two devices with nothing but a screen and a camera.

■□■ Send → Pick a file, start the stream. Up to %MAX_FILE_LABEL%. ◉ Receive ← Point a camera at the sending screen.

From a terminal

The sender also runs as a terminal command — macOS and Linux, python3 and nothing else.

curl -fsSL https://hish-l.github.io/transfer/qr.sh | bash -s -- myfile.pdf

That pipes a URL into a shell. To read it first:

curl -fsSLO https://hish-l.github.io/transfer/qr.sh && less qr.sh

How it holds together

The sender streams fountain-coded frames endlessly, so a dropped or blurry read just costs time — the receiver rebuilds the file from any sufficient set, in any order, and only shows it to you once its SHA-256 matches.

What this is not

Not encrypted — anything on the sending screen is readable by any camera pointed at it. Encrypt the file first if that matters.
