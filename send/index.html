Stream settings

Bigger frames move more data per code but need a steadier camera. If the receiver sits at zero, drop to 1465 bytes and 24 fps — that combination reads off almost anything. Changing any setting restarts the stream.

Aim for

Fill the receiving camera's frame with the code and hold still. The stream never ends and never knows whether anyone is listening — stop it yourself once the other device says the file is verified.
